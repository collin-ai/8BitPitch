### 2. Phase 09-01: Mobile Numberpad — Base Implementation

A new `utils/numpad.js` module plus supporting changes provide a toggleable on-screen numberpad for mobile users. Prevents native keyboard opening (and associated viewport zoom that obscures drill questions).

**Files changed:**

| File | Changes |
|------|---------|
| `utils/numpad.js` | NEW — `window.BitPitch.Numpad` module: init, toggle, onDrillEnd, pressKey |
| `index.html` | Added `#numpad-panel` (19 keys, 5-col grid) inside `.drill-body`; added `<script src="utils/numpad.js">` |
| `style.css` | Added `#numpad-toggle`, `#numpad-panel`, `.np-btn`, `.np-wide`, `.numpad-mode` CSS |
| `app.js` | `goHome` + `showSummary` call `onDrillEnd()`; `init()` called at boot |

**How it works:** Toggle button (`#`) is injected into `.drill-card` via MutationObserver after each question renders. When active: `inputmode="none"` on all `.drill-input` elements (no native keyboard); `.numpad-mode` on body sets `font-size:16px` (iOS zoom fix); `#numpad-panel` shown below drill card. Panel hides during feedback phase, re-shows on next question.

### Refinement B: ENT key directly submits

**What:** ENT on the numpad should click the submit button directly, not dispatch a keyboard Enter event to `document`.

**Current issue:** `document.onkeydown` Enter handlers are for Enter-to-NEXT (feedback phase), not for submit. During the question phase, each exercise has `input.onkeydown` for Enter-to-submit (with `e.stopPropagation()`), so dispatching to `document` doesn't submit.

**Fix in `utils/numpad.js` `pressKey('enter')`:**
```javascript
case 'enter': {
  var submitBtn =
    document.getElementById('submit-btn') ||
    document.getElementById('submit-all-btn') ||
    document.querySelector('#drill-area .btn-primary:not([disabled])');
  if (submitBtn && !submitBtn.disabled) {
    submitBtn.click();
  } else {
    // Fallback: dispatch Enter for Enter-to-NEXT (feedback phase)
    var evt = new KeyboardEvent('keydown', { key: 'Enter', bubbles: true, cancelable: true });
    document.dispatchEvent(evt);
  }
  return;
}
```
