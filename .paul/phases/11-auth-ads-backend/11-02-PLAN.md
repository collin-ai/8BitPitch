<objective>
## Goal
Create a `scores` table in Supabase with RLS, add a `saveScore()` function to `utils/supabase.js`, and hook it into `showSummary()` in app.js so that logged-in users' drill scores are persisted to Supabase after every drill. Guest scores are silently discarded.

## Purpose
Phase 11-01 establishes identity (AppState.currentUser). This plan uses that identity to persist scores. Without this, session scores exist only in memory and are lost on refresh. Saved scores are the data source for the Profile screen (Phase 11-03 / 12-03) and the leveling system (Phase 12-04).

## Output
- Supabase `scores` table created via SQL (documented here; applied manually in dashboard)
- `window.BitPitch.Supabase.saveScore(scoreObj)` in utils/supabase.js
- `showSummary()` in app.js calls saveScore after each drill (logged-in users only)
- No UI changes — score persistence is invisible to the user in this plan
</objective>

    );

    ALTER TABLE public.scores ENABLE ROW LEVEL SECURITY;

    CREATE POLICY "Users can insert own scores"
      ON public.scores FOR INSERT
      WITH CHECK (auth.uid() = user_id);

    CREATE POLICY "Users can select own scores"
      ON public.scores FOR SELECT
      USING (auth.uid() = user_id);

<task type="auto">
  <name>Add saveScore() to utils/supabase.js</name>
  <files>utils/supabase.js</files>
  <action>
    In the `window.BitPitch.Supabase` IIFE (created in Phase 11-01), add:

    ```js
    saveScore: async function(scoreObj) {
      // scoreObj: { exercise_id, mode, difficulty, correct_count, total_questions, total_ms }
      var client = getClient();
      var session = await client.auth.getSession();
      var user = session.data.session ? session.data.session.user : null;
      if (!user) return;   // guest — discard silently

      var row = {
        user_id:         user.id,
        exercise_id:     scoreObj.exercise_id,
        mode:            scoreObj.mode,
        difficulty:      scoreObj.difficulty,
        correct_count:   scoreObj.correct_count,
        total_questions: scoreObj.total_questions,
        total_ms:        scoreObj.total_ms
      };

      var result = await client.from('scores').insert(row);
      if (result.error) {
        console.error('[BitPitch] saveScore failed:', result.error.message);
      }
    }
    ```

    Notes:
    - Re-fetch session inside saveScore rather than relying on AppState.currentUser — this guards against stale state after a session expiry
    - The function is async; the caller (showSummary) does not need to await it — fire-and-forget is fine
    - Do not modify any other function in utils/supabase.js
  </action>
