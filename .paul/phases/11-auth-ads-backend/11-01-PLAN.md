<task type="auto">
  <name>Wire app.js — AppState.currentUser, session restore, auth handlers, username strip</name>
  <files>app.js</files>
  <action>
    Add to AppState object:
      currentUser: null   // null = guest; object = { id, email } from Supabase

    **On boot** (after renderHome(), before Numpad.init()):
      async function restoreSession() {
        var user = await window.BitPitch.Supabase.getCurrentUser();
        AppState.currentUser = user || null;
        updateAuthStrip();
      }
      restoreSession();

    **AppState.doRegister():**
      - Read #register-username and #register-pin values
      - Validate client-side (username regex, PIN regex) — show #register-error if invalid
      - Call Supabase.register(username, pin)
      - On success: set AppState.currentUser, updateAuthStrip(), AppState.goHome()
      - On error: show Supabase error message in #register-error (map common errors:
          "User already registered" → "USERNAME TAKEN. CHOOSE ANOTHER.")

    **AppState.doSignIn():**
      - Read #signin-username and #signin-pin
      - Validate client-side
      - Call Supabase.signIn(username, pin)
      - On success: set AppState.currentUser, updateAuthStrip(), AppState.goHome()
      - On error: show "INCORRECT USERNAME OR PIN." in #signin-error

    **AppState.doSignOut():**
      - Call Supabase.signOut()
      - AppState.currentUser = null
      - updateAuthStrip()
      - showScreen('login-entry')

    **updateAuthStrip():**
      - If AppState.currentUser: extract username from email
          (email = username@bitpitch.local → strip @bitpitch.local)
        Show: "{USERNAME} | [SIGN OUT]" in #auth-strip div on home screen
      - If guest: hide #auth-strip (or show nothing)

    **index.html** — add #auth-strip div to #screen-home above the drill grid:
      <div id="auth-strip" class="auth-strip hidden"></div>

    Wire CREATE BETA ACCOUNT button (added in 10-04 as placeholder) to showScreen('register').
    Wire SIGN IN link (if present on login-entry) to showScreen('sign-in').

    Avoid: blocking the PLAY AS GUEST path; guest flow must remain unchanged.
  </action>
