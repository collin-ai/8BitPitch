<objective>
## Goal
Implement the ads system: track how many exercises have been completed in the current session per mode (drill / practice). After every 8th drill exercise or 16th practice exercise, show a full-screen interstitial ad before the score/summary screen is revealed. The ad is a placeholder featuring creator branding — no real ad network.

## Purpose
This establishes the monetisation structure for the beta. The ad plays between the last question and the score screen — the highest-attention moment, when the player is eager to see their result. Using a placeholder now lets the slot be replaced with a real ad unit later without touching exercise logic.

## Output
- `#screen-ad` in index.html — full-screen interstitial ad placeholder
- `AppState._drillCount` / `AppState._practiceCount` trackers incremented at exercise completion
- `AppState._pendingSummary` — stores the summary callback/data while the ad plays
- `maybeShowAd(proceedFn)` in app.js — checks counter; if threshold met, shows ad then calls proceedFn on CONTINUE; otherwise calls proceedFn immediately
- Ad screen: creator message, 5-second countdown, CONTINUE button activates after countdown
- `continueFromAd()` — calls the stored proceed function (shows summary screen)
- CSS for ad screen in style.css
</objective>

    **Add counter and pending-summary state to AppState:**
    ```js
    _drillCount:    0,       // increments after each drill-mode exercise
    _practiceCount: 0,       // increments after each practice-mode exercise
    _adProceedFn:   null,    // stored callback — called by continueFromAd()
    ```

    **maybeShowAd(proceedFn)** — called at the point where showSummary() would normally be called:
    ```js
    AppState.maybeShowAd = function(proceedFn) {
      // Increment counter for current mode
      if (AppState.mode === 'drill') {
        AppState._drillCount++;
      } else {
        AppState._practiceCount++;
      }

      var threshold = AppState.mode === 'drill' ? 8 : 16;
      var count = AppState.mode === 'drill' ? AppState._drillCount : AppState._practiceCount;

      if (count % threshold === 0) {
        AppState._adProceedFn = proceedFn;
        AppState._showAd();
      } else {
        proceedFn();
      }
    };
    ```

    **AppState._showAd():**
    ```js
    AppState._showAd = function() {
      var btn = document.getElementById('ad-continue-btn');
      var countEl = document.getElementById('ad-countdown');
      btn.disabled = true;
      var secs = 5;
      countEl.textContent = secs;
      showScreen('ad');

      var interval = setInterval(function() {
        secs--;
        countEl.textContent = secs;
        if (secs <= 0) {
          clearInterval(interval);
          btn.disabled = false;
        }
      }, 1000);
    };
    ```

    **AppState.continueFromAd():**
    ```js
    AppState.continueFromAd = function() {
      var fn = AppState._adProceedFn;
      AppState._adProceedFn = null;
      if (fn) fn();
    };
    ```
