<objective>
## Goal
Extend the Sound module with four new sounds: a splash jingle (plays during the word drop-in animation), a UI click sound (plays on every navigation button tap), a level-up fanfare (plays when a player reaches a new level on an exercise), and a session-complete flourish (plays when the summary screen appears). All sounds respect the existing `bp_sound` mute state.

## Purpose
Phase 10-02 added correct/wrong feedback sounds tied to drill answers. The rest of the app is silent — navigation, splash, leveling, and session completion have no audio identity. Adding these four sounds makes the app feel alive end-to-end without touching any exercise logic.

## Output
- `window.BitPitch.Sound.playClick()` — short UI click tone
- `window.BitPitch.Sound.playSplash()` — ascending jingle synced to splash word drop-ins
- `window.BitPitch.Sound.playLevelUp()` — fanfare for reaching a new exercise level
- `window.BitPitch.Sound.playSessionComplete()` — flourish on summary screen appearance
- Click sound wired to all navigation buttons (mode bar tabs, MENU buttons, screen-to-screen buttons)
- Splash sound wired into `runSplash()` in app.js
- Level-up sound wired into `BitPitch.Levels.recordCorrect()` threshold check
- Session complete sound wired into `showSummary()`
</objective>

    Inside the `window.BitPitch.Sound` IIFE, add four private play functions and expose them on the returned object.

    **_playClick(ctx)** — single short square-wave tick:
    ```js
    function _playClick(ctx) {
      var t = ctx.currentTime;
      var osc  = ctx.createOscillator();
      var gain = ctx.createGain();
      osc.connect(gain);
      gain.connect(ctx.destination);
      osc.type = 'square';
      osc.frequency.value = 440;           // A4 — neutral, not too bright
      gain.gain.setValueAtTime(0.12, t);
      gain.gain.exponentialRampToValueAtTime(0.001, t + 0.04);
      osc.start(t);
      osc.stop(t + 0.04);
    }
    ```

    **_playSplash(ctx)** — four staggered ascending tones matching word drop timing (~350ms apart):
    ```js
    function _playSplash(ctx) {
      var freqs = [220, 277, 330, 440];    // A3, C#4, E4, A4 — ascending major arpeggio
      freqs.forEach(function(freq, i) {
        var t     = ctx.currentTime + i * 0.35;
        var osc   = ctx.createOscillator();
        var gain  = ctx.createGain();
        osc.connect(gain);
        gain.connect(ctx.destination);
        osc.type = 'square';
        osc.frequency.value = freq;
        gain.gain.setValueAtTime(0.2, t);
        gain.gain.exponentialRampToValueAtTime(0.001, t + 0.25);
        osc.start(t);
        osc.stop(t + 0.25);
      });
    }
    ```

    **_playLevelUp(ctx)** — triumphant ascending run followed by a held chord:
    ```js
    function _playLevelUp(ctx) {
      var t = ctx.currentTime;
      // Quick ascending run: C5 E5 G5 C6
      var run = [523, 659, 784, 1047];
      run.forEach(function(freq, i) {
        var osc  = ctx.createOscillator();
        var gain = ctx.createGain();
        osc.connect(gain);
        gain.connect(ctx.destination);
        osc.type = 'square';
        osc.frequency.value = freq;
        var start = t + i * 0.08;
        gain.gain.setValueAtTime(0.2, start);
        gain.gain.exponentialRampToValueAtTime(0.001, start + 0.1);
        osc.start(start);
        osc.stop(start + 0.1);
      });
      // Held chord on top: C5 + E5 + G5 together after run
      var chordStart = t + run.length * 0.08 + 0.05;
      [523, 659, 784].forEach(function(freq) {
        var osc  = ctx.createOscillator();
        var gain = ctx.createGain();
        osc.connect(gain);
        gain.connect(ctx.destination);
        osc.type = 'square';
        osc.frequency.value = freq;
        gain.gain.setValueAtTime(0.15, chordStart);
        gain.gain.exponentialRampToValueAtTime(0.001, chordStart + 0.5);
        osc.start(chordStart);
        osc.stop(chordStart + 0.5);
      });
    }
    ```

    **_playSessionComplete(ctx)** — two-beat flourish, warmer than correct chime:
    ```js
    function _playSessionComplete(ctx) {
      var t = ctx.currentTime;
      // Beat 1: C5 + G5 together
      // Beat 2: C5 + E5 + G5 + C6 together (full chord, louder)
      var beat1 = [[523, 784]];
      var beat2 = [[523, 659, 784, 1047]];

      beat1[0].forEach(function(freq) {
        var osc  = ctx.createOscillator();
        var gain = ctx.createGain();
        osc.connect(gain);
        gain.connect(ctx.destination);
        osc.type = 'square';
        osc.frequency.value = freq;
        gain.gain.setValueAtTime(0.15, t);
        gain.gain.exponentialRampToValueAtTime(0.001, t + 0.18);
        osc.start(t);
        osc.stop(t + 0.18);
      });

      beat2[0].forEach(function(freq) {
        var osc  = ctx.createOscillator();
        var gain = ctx.createGain();
        osc.connect(gain);
        gain.connect(ctx.destination);
        osc.type = 'square';
        osc.frequency.value = freq;
        var s = t + 0.22;
        gain.gain.setValueAtTime(0.2, s);
        gain.gain.exponentialRampToValueAtTime(0.001, s + 0.4);
        osc.start(s);
        osc.stop(s + 0.4);
      });
    }
    ```

    **Click sound — event delegation:**
    Add once, near the bottom of app.js in the startup block (after DOMContentLoaded or equivalent):
    ```js
    document.addEventListener('click', function(e) {
      var el = e.target;
      // Walk up to find a .btn ancestor (handles clicks on child spans inside buttons)
      while (el && el !== document.body) {
        if (el.classList && el.classList.contains('btn')) {
          if (window.BitPitch && window.BitPitch.Sound) {
            window.BitPitch.Sound.playClick();
          }
          break;
        }
        el = el.parentElement;
      }
    }, { passive: true });
    ```
