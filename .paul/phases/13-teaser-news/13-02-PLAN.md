<objective>
## Goal
Place a mini version of the Profile Widget above the drill grid on the home screen. The widget reuses `AppState.renderProfileWidget()` from Phase 12-02. A long-press (500ms hold) on the widget navigates to the Profile & Settings screen.

## Purpose
The home screen currently has no identity signal — the user lands on a grid of drills with no sense of their progress or who they are. Adding the widget here gives every session a personalised start and makes XP/levels immediately visible without navigating away.

## Output
- A `#home-widget-container` div added to `#screen-home` above the drill grid
- `renderProfileWidget('home-widget-container')` called each time the home screen is rendered
- Long-press handler on the widget (500ms) → navigates to Profile & Settings
- Short tap on widget does nothing (does not block drill grid interaction)
- CSS for widget container in context of the home screen
</objective>

<task type="auto">
  <name>Add #home-widget-container to #screen-home and wire renderProfileWidget in renderHome()</name>
  <files>index.html, app.js</files>
  <action>
    **index.html** — inside `#screen-home`, add a container div as the first child (before the drill grid):
    ```html
    <div id="home-widget-container"></div>
    ```

    **app.js** — in `renderHome()`, add at the start of the function body:
    ```js
    if (window.BitPitch && window.BitPitch.Levels) {
      AppState.renderProfileWidget('home-widget-container');
    }
    ```

    Then wire the long-press handler immediately after the widget is rendered.
    Add a helper function (called once, called from renderHome after widget render):

    ```js
    function _wireWidgetLongPress() {
      var el = document.getElementById('home-widget-container');
      if (!el || el.dataset.longpressWired) return;
      el.dataset.longpressWired = '1';

      var _lpTimer = null;

      function _startPress() {
        _lpTimer = setTimeout(function() {
          _lpTimer = null;
          AppState.showProfile();
        }, 500);
      }

      function _cancelPress() {
        if (_lpTimer) {
          clearTimeout(_lpTimer);
          _lpTimer = null;
        }
      }

      el.addEventListener('mousedown', _startPress);
      el.addEventListener('mouseup', _cancelPress);
      el.addEventListener('mouseleave', _cancelPress);
      el.addEventListener('touchstart', _startPress, { passive: true });
      el.addEventListener('touchend', _cancelPress);
      el.addEventListener('touchcancel', _cancelPress);
    }
    ```

    Call `_wireWidgetLongPress()` after `renderProfileWidget` in `renderHome()`.

    The `dataset.longpressWired` guard prevents duplicate listeners being added on each home screen visit (renderHome may be called multiple times per session).

    Do not change any drill card click handlers or the drill grid layout.
  </action>
  <verify>Open home screen — widget visible above drill grid. Hold widget 500ms → Profile & Settings opens. Tap quickly → nothing happens. Tap a drill card → normal drill launch, no interference.</verify>
