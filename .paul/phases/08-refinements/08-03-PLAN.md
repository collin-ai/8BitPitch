# Plan 08-03: drill-timer-q Same Row as drill-progress

## What
Move the `drill-timer-q` element out of its absolute-position anchor and into a flex row alongside `div.drill-progress`, so the per-question timer and progress counter share the same horizontal row within the drill card.

## Why
Currently `drill-timer-q` is `position: absolute; top: 12px; right: 12px` which overlaps the card's top-right corner. The user wants it flush in the same row as the progress indicator, which is cleaner and avoids the absolute-position overlap.

## Files Affected
- `style.css`
- `exercises/ex01-percentage-snap.js`
- `exercises/ex02-multiples.js`
- `exercises/ex03-double-triple-halve.js`
- `exercises/ex04-triangle-drill.js`
- `exercises/ex05-growth-rate.js`
- `exercises/ex06-break-even.js`
- `exercises/ex07-tam-estimation.js`
- `exercises/ex08-valuation-challenge.js`

## CSS Changes (style.css)

### 1. Remove absolute positioning from `.drill-timer-q`

**Find:**
```css
.drill-timer-q {
  position: absolute;
  top: 12px;
  right: 12px;
  font-size: 8px;
  color: var(--yellow);
}
```

**Replace with:**
```css
.drill-timer-q {
  font-size: 8px;
  color: var(--yellow);
}
```

### 2. Remove `margin-bottom` from `.drill-progress` (it will be owned by `.progress-row`)

**Find:**
```css
.drill-progress {
  font-size: 8px;
  color: var(--text-dim);
  margin-bottom: 12px;
}
```

**Replace with:**
```css
.drill-progress {
  font-size: 8px;
  color: var(--text-dim);
}
```

### 3. Add `.progress-row` rule after `.drill-progress` block

Insert after the `.drill-progress` block:
```css
.progress-row {
  display: flex;
  justify-content: space-between;
  align-items: center;
  margin-bottom: 12px;
}
```

## HTML Template Changes (exercise JS files)

In every exercise's `showQuestion()` / `showOp()` / `showRate()` / `showPitch()` function, the drill-card HTML currently starts with:

```javascript
'<div class="drill-card">' +
  '<span class="drill-timer-q" id="drill-timer-q"></span>' +
  '<div class="drill-progress">...[progress text]...</div>' +
```

Wrap both elements in a `.progress-row` div, with `drill-progress` first and `drill-timer-q` second:

```javascript
'<div class="drill-card">' +
  '<div class="progress-row">' +
    '<div class="drill-progress">...[progress text]...</div>' +
    '<span class="drill-timer-q" id="drill-timer-q"></span>' +
  '</div>' +
```

Apply this pattern to each file:
