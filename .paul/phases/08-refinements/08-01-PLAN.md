# Plan 08-01: Center diff-exp-title

## What
Center the `diff-exp-title` span so it is visually centered over the full width of the `diff-exp-header`, not just within the remaining space after the MENU button.

## Why
Currently `.diff-exp-title` flows inline after the MENU button and is left-aligned relative to the container. It should be centred the same way `.drill-title` is centred in the drill header.

## Files Affected
- `style.css`

---

## Changes

### style.css

**Find (`.diff-exp-header` block):**
```css
.diff-exp-header {
  display: flex;
  align-items: center;
  gap: 12px;
  width: 100%;
  max-width: 640px;
  padding-bottom: 8px;
  border-bottom: 2px solid var(--border);
}
```

**Replace with:**
```css
.diff-exp-header {
  display: flex;
  align-items: center;
  gap: 12px;
  width: 100%;
  max-width: 640px;
  padding-bottom: 8px;
  border-bottom: 2px solid var(--border);
  position: relative;
}
```

---

**Find (`.diff-exp-title` block):**
```css
.diff-exp-title {
  font-size: 9px;
  color: var(--yellow);
  letter-spacing: 1px;
}
```

**Replace with:**
```css
.diff-exp-title {
  position: absolute;
  left: 50%;
  transform: translateX(-50%);
  font-size: 9px;
  color: var(--yellow);
  letter-spacing: 1px;
  white-space: nowrap;
}
```

---

## Notes
- The MENU button stays left-aligned; the title is absolutely centred over the full header width.
- `white-space: nowrap` prevents wrapping if the viewport is narrow.
- No HTML or JS changes needed.
