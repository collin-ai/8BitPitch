# Plan 08-02: Feedback Box Overhaul

## What
Restructure every exercise's feedback box to a consistent 5-item order. Two additional behaviours change globally.

## New Feedback Order (all exercises)
1. **Status label** — CORRECT! / WRONG / GOOD RANGE! / RANGE OFF / etc.
2. **Acceptable Range** — computed range of accepted values at the current difficulty (renamed from "Correct Range" in ex02)
3. **Math explained** — calculation breakdown (moved after Acceptable Range)
4. **Your answer** — shown for **both** correct AND incorrect results
   - Correct: display the raw string exactly as the user typed it
   - Wrong: display the parsed/formatted value
   - Pass or blank: display "PASS"
5. **Time** — drill mode only; position unchanged

## Global Behaviour Changes
- **Blank input → PASS**: In every exercise's submit handler, check whether any required input is empty before processing. If so, trigger the pass flow instead.
- **Raw input capture**: Capture `input.value.trim()` (raw string) in each submit handler and pass it to `showFeedback` so correct answers can display "exactly as inputted."

## Files Affected
- `exercises/ex01-percentage-snap.js`
- `exercises/ex02-multiples.js`
- `exercises/ex03-double-triple-halve.js`
- `exercises/ex04-triangle-drill.js`

- `exercises/ex07-tam-estimation.js` *(blank-input → PASS only; self-grade UI not restructured)*

  function showFeedback(type, tri, correct, isOk, elapsed, rawInput, isPassed) {
    var cls = isOk ? 'feedback-correct' : 'feedback-wrong';
    var msg = isOk ? 'CORRECT!' : 'WRONG';
    var dp = (type === 'ask' && tri.equity === 33 && context.difficulty === 'HARD') ? 2 : 0;
    var displayCorrect = (type === 'equity') ? correct + '%' :
                         dp > 0 ? R.formatMoneyDp(correct, dp) : R.formatMoney(correct);

    // Acceptable range
