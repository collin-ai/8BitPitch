<task type="auto">
  <name>Add CONTACT CREATOR button to #screen-home and style it</name>
  <files>index.html, style.css</files>
  <action>
    **index.html** — inside `#screen-home`, after the drill grid container (`.drill-grid` or equivalent), add:
    ```html
    <div class="contact-row">
      <a class="contact-btn"
         href="https://forms.gle/Q1gpSmKsx6o5AGTT8"
         target="_blank"
         rel="noopener noreferrer">CONTACT CREATOR</a>
    </div>
    ```

    Use an `<a>` tag (not a `<button>`) so the browser handles new-tab opening natively on both desktop and mobile.

    **style.css** — add:
    ```css
    /* ── Contact Creator ── */
    .contact-row {
      text-align: center;
      margin-top: 16px;
      padding-bottom: 12px;
    }

    .contact-btn {
      font-family: var(--font);
      font-size: 7px;
      color: var(--dim);
      letter-spacing: 1px;
      text-decoration: none;
      border: 1px solid var(--dim);
      padding: 6px 12px;
    }

    .contact-btn:hover,
    .contact-btn:active {
      color: var(--fg);
      border-color: var(--fg);
    }
    ```

    Do NOT use a `<button onclick="window.open(...)">` pattern — the `<a target="_blank">` approach is correct for user-initiated navigation and avoids popup-blocker issues.
    Do NOT add rel="opener" — keep noopener for security.
  </action>
  <verify>Open home screen — CONTACT CREATOR appears below the drill grid. Click it — Google Form opens in a new tab. App remains on home screen.</verify>
