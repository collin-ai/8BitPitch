<objective>
## Goal
Build the splash animation screen and the log-in entry screen. The splash drops in the words "8", "BIT", "PITCH", "LITE" one at a time from above, then fades to the log-in entry screen. The log-in entry screen has two buttons: PLAY AS GUEST (navigates to home) and CREATE BETA ACCOUNT (stub — wired for Phase 11).

## Purpose
Currently the app opens directly to the home screen. This plan establishes a proper entry flow: splash → log-in entry → home or auth. The splash communicates identity immediately. The log-in entry gate is needed before Phase 11 (auth) can be wired in.

## Output
- `#screen-splash` in index.html with 4 animated word elements
- `#screen-login-entry` in index.html with PLAY AS GUEST + CREATE BETA ACCOUNT buttons
- Splash CSS in style.css (drop-in animation, fade-out transition)
- `runSplash()` in app.js (sequenced JS animation, then advances to login-entry)
- App startup flow updated: splash runs on page load instead of renderHome()
</objective>

    **runSplash()** — sequenced word drop-in then advance:
    ```js
    function runSplash() {
      var words = ['splash-w1','splash-w2','splash-w3','splash-w4'];
      var delay = 0;
      words.forEach(function(id, i) {
        delay += (i === 0 ? 200 : 350);
        setTimeout(function() {
          document.getElementById(id).classList.add('landed');
        }, delay);
      });
      // pause after last word, then fade and advance
      setTimeout(function() {
        var splash = document.getElementById('screen-splash');
        splash.classList.add('fading');
        setTimeout(function() {
          splash.classList.add('hidden');
          showScreen('login-entry');
        }, 400);
      }, delay + 900);
    }
    ```

    **AppState.playAsGuest():**
    ```js
    AppState.playAsGuest = function() {
      AppState.currentUser = null;   // guest — no session
      document.getElementById('mode-bar').style.display = '';   // restore mode bar
      renderHome();
      showScreen('home');
    };
    ```
