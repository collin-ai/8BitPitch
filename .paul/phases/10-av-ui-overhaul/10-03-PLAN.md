<objective>
## Goal
Redesign the mode bar from 4 tabs (DRILL / PRACTICE / HIGH SCORES / DIFFICULTY EXPLAINED)
to 3 tabs (MODE SELECT / PROFILE & SETTINGS / 8BITPITCH NEWS), and add three new screen shells.

## Purpose
The old tab structure tied mode selection to the bar directly. The new design separates navigation
from mode selection: MODE SELECT is a screen where the user picks drill vs practice (built in 12-01).
PROFILE & SETTINGS and 8BITPITCH NEWS are new screens (filled in 11-03/12-03 and 13-03).

## Output
- 3-tab mode bar with sub-label on MODE SELECT tab
- #screen-mode-select (shell, for 12-01)
- #screen-profile (shell, for 11-03 / 12-03)
- #screen-news (shell with placeholder text, for 13-03)
</objective>
