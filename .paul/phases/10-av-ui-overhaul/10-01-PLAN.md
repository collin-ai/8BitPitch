## Goal
Replace the favicon suppression tag (`data:,`) in index.html with a real inline SVG favicon: a yellow "8" on a black rounded square.

## Purpose
The current `data:,` tag only silences the browser's 404 request — there is no visible icon. A real favicon improves the app's perceived completeness and is the smallest possible scope to open Phase 10.

## Output
`index.html` `<head>`: one tag replaced. Favicon visible in browser tab.

<task type="auto">
  <name>Replace data:, suppression tag with inline SVG favicon</name>
  <files>index.html</files>
  <action>
    In index.html <head>, find the existing favicon tag:
      <link rel="icon" href="data:,">

    Replace with:
      <link rel="icon" href="data:image/svg+xml,<svg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 32 32'><rect width='32' height='32' rx='6' fill='black'/><text x='50%' y='54%' dominant-baseline='middle' text-anchor='middle' font-family='monospace' font-size='22' font-weight='bold' fill='%23FFD700'>8</text></svg>">

    Notes:
    - %23 is the percent-encoded form of # (required in data URIs)
    - rx='6' gives rounded corners on the black square
    - fill='%23FFD700' is yellow — matches the existing 8-bit color palette
    - font-family='monospace' ensures the 8 is blocky and readable at small sizes
    - Do NOT create a separate favicon.ico file
    - Do NOT change any other part of index.html
  </action>
  <verify>Open index.html in Chrome/Safari — browser tab shows yellow 8 on black square. DevTools Network tab shows no favicon 404.</verify>
  <done>AC-1 and AC-2 satisfied</done>
</task>
