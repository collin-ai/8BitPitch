<objective>
## Goal
Style `#drill-difficulty` to match the visual height of MENU/RESTART buttons (same border + padding), and true-centre the drill title so it remains centred after the badge gains visual weight.

## Purpose
Currently the difficulty span is bare text — no border, no padding — so it looks visually lighter than the buttons beside it and throws off the header balance. The title uses `flex: 1` which centres it within its allocated space but not within the full header width. After this plan, the header reads as three balanced regions: buttons left | title centred | badge+timer right.

## Output
One file modified: `style.css`
- `#drill-difficulty` becomes a visible badge matching button height
- `.drill-title` is absolutely centred across the full header width
</objective>

<task type="auto">
  <name>Style difficulty badge + true-centre drill title</name>
  <files>style.css</files>
  <action>
    Three CSS changes — no HTML changes needed.

    1. On `.drill-header`: add `position: relative;`
       Needed so `.drill-title` can be absolutely positioned relative to the header box.

    2. On `.drill-title`: replace `flex: 1;` with absolute centring:
       ```
       position: absolute;
       left: 50%;
       top: 50%;
       transform: translate(-50%, -50%);
       ```
       Remove `flex: 1`. Keep existing `text-align: center`, `font-size`, `color`, `letter-spacing`.
       The title is now truly centred in the header regardless of left/right element widths.

    3. On `#drill-difficulty`: add badge styling to match `.back-btn` / `.restart-btn`:
       - `font-size: 8px` (was 7px — match button font size)
       - `border: 2px solid var(--text-dim)`
       - `padding: 6px 10px`
       - `box-shadow: 2px 2px 0 #000`
       - `margin-left: auto` (pins badge to the right in the flex flow — pushes it away from MENU/RESTART toward the timer)
       Keep existing `color: var(--text-dim)` and `white-space: nowrap`.

    Why no HTML changes:
    With the title out of flex flow (position: absolute), the flex items are:
    [MENU] [RESTART] [auto-margin gap] [difficulty badge] [timer]
    `margin-left: auto` on difficulty handles the rightward pinning.

    Overlap check: longest drill name ("DOUBLE TRIPLE HALVE") at 9px Press Start 2P is ~168px wide.
    Centred at 320px in a 640px header, it spans 236–404px. Buttons end ~148px. Badge starts ~462px.
    Both gaps (~88px left, ~58px right) are sufficient — no overlap risk.
  </action>
