# Plan 06-05: Difficulty Explained Page

**Phase:** 6 — Refinements
**Status:** PLAN (ready to apply)

---

## Objective

Replace the non-functional SETTINGS tab with a static "Difficulty Explained" info page that explains the tolerance system to the player.

---

## Scope

- `index.html` — rename tab label; add new `#screen-difficulty` screen
- `app.js` — wire `showMenuSettings` to show the new screen
- `style.css` — add styles for the info page content

Easy/Medium/Hard buttons on the "Are you ready?" screen are **unchanged**.

---

## Changes

```html

```

**Replace with:**
