# Plan 05-02: Drill Launch + Navigation

## Objective

Add a pre-drill "Are you ready?" screen that gates exercise launch and timing. Add RESTART DRILL navigation. Show difficulty in the drill header. Make the drill title act as a restart trigger. Keep all changes in app.js and index.html — no exercise files touched.

## Acceptance Criteria

| # | Given | When | Then |
|---|-------|------|------|
| 1 | Player selects a drill from the menu | The drill screen opens | "Are you ready?" screen appears before any exercise content renders |
| 2 | "Are you ready?" screen is shown | Player clicks BEGIN | Exercise launches and timing starts |
| 3 | Player is on the "Are you ready?" screen | Player clicks TUTORIAL | Tutorial mode is entered for that drill (placeholder alert acceptable) |
| 4 | Player is in an active drill | Player clicks MENU | Returns to home (existing behaviour preserved) |
| 5 | Player is in an active drill (past BEGIN) | Player clicks RESTART DRILL | Confirmation prompt appears; YES returns to "Are you ready?" for same drill; NO dismisses |
| 6 | Player is in an active drill (past BEGIN) | Player clicks the drill title | Same confirmation as RESTART DRILL |
| 7 | Player is on "Are you ready?" screen | Screen is visible | "Are you ready?" text explains: clicking the drill title will restart |
| 8 | Player is viewing any drill screen | Drill header is visible | Current difficulty (e.g. "EASY") is shown between the drill title and the right side of the header |

## Boundaries — Do NOT Change

- No exercise files (ex01–ex08) — zero changes to those files this plan
- No changes to scoring, session, or summary logic
- No changes to style.css beyond what is needed for the new header elements and ready-screen layout
- Mode bar behaviour unchanged

## Tasks

### Task 1 — "Are you ready?" screen in app.js

**File:** `app.js`
**Action:** Modify `AppState.startExercise()` to render a ready screen into `#drill-area` instead of immediately calling the exercise function. The ready screen shows:
- Drill icon (large, in drill colour)
- Drill name
- One line: "CLICK THE TITLE TO RESTART AT ANY TIME"
- Two buttons: BEGIN and TUTORIAL

Only when BEGIN is clicked does the actual exercise function get called (and timing begins).
Track that the player has passed BEGIN with a flag on AppState (`AppState.drillStarted = false` reset on each `startExercise`, set to `true` on BEGIN).

**Verify:** Select any drill → "Are you ready?" screen appears. Clicking BEGIN launches the exercise. Timer doesn't start before BEGIN.

---

### Task 2 — RESTART DRILL button + drill title click in index.html + app.js

**File:** `index.html`
**Action:** In the `#screen-drill` header, add a RESTART DRILL button next to the existing MENU button.

**File:** `app.js`
**Action:**
- Implement `AppState.restartDrill()`: if `AppState.drillStarted` is true, show a `confirm()` dialog ("RESTART DRILL?"). On YES, call `AppState.startExercise(AppState.currentExercise)`. On NO, do nothing.
- If `AppState.drillStarted` is false (still on ready screen), restart without confirmation.
- Add an `onclick` to `#drill-title` that calls `AppState.restartDrill()`.
- Wire the RESTART DRILL button's `onclick` to `AppState.restartDrill()`.

**Verify:** On the ready screen, RESTART DRILL reloads immediately. After BEGIN, RESTART DRILL shows a confirmation. Clicking the title does the same.

---

### Task 3 — Difficulty display in drill header

**File:** `index.html`
**Action:** Add a `<span id="drill-difficulty">` between `#drill-title` and `#drill-timer` in the drill header.

**File:** `app.js`
**Action:** Add `AppState.difficulty = 'EASY'` to the AppState object (default). In `startExercise()`, update `#drill-difficulty` to display the current difficulty (e.g. "[ EASY ]").

**Verify:** Drill header shows difficulty label. Changing `AppState.difficulty` in console updates it correctly (full difficulty-switching UI is Plan 05-08).
