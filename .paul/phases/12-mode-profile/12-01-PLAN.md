<objective>
## Goal
Build the Mode Select screen content — three selectable boxes (Practice, Drill, Coming Soon) each with an icon and description. Wire the MODE SELECT tab to navigate to this screen and display the active mode name as a sub-label on the tab button.

## Purpose
Phase 10-03 builds the Mode Select tab and screen shell. This plan fills in the screen content and completes the mode-switching UX: the user sees a clear 3-choice menu with visual context for what each mode means.

## Output
- `#screen-mode-select` populated with 3 mode boxes
- MODE SELECT tab shows active mode sub-label (DRILL or PRACTICE)
- Selecting a mode updates `AppState.mode`, updates the sub-label, and returns to home
- Coming Soon box routes to `#screen-news`
</objective>

    In `#screen-mode-select` (created in 10-03), add three `.mode-box` divs:

    PRACTICE box:
    - Icon: a pixel-art style icon (SVG inline or Unicode) representing practice/book
    - Title: PRACTICE
    - Description: XP IS NOT COUNTED

    DRILL box:
    - Icon: representing competitive/drill (e.g. lightning bolt or target)
    - Title: DRILL
    - Description: XP IS COUNTED

    COMING SOON box:
    - Icon: star or clock icon
    - Title: COMING SOON
    - Description: SEE WHAT'S NEXT

    Each box: full-width, ~90px tall, flex row (icon left, text right), bordered with var(--border), cursor pointer.
    Active mode box is highlighted (background: var(--accent) or similar).

    In style.css, add:
    - `.mode-box`: layout, border, padding, hover state
    - `.mode-box.active`: highlighted background
    - `.mode-box-icon`: fixed-width left column (~32px)
    - `.mode-box-text .mode-box-title`: uppercase, font-size 8px
    - `.mode-box-text .mode-box-desc`: dim color, font-size 7px

    onclick for PRACTICE: AppState.selectMode('practice')
    onclick for DRILL: AppState.selectMode('drill')
    onclick for COMING SOON: AppState.showNews()

    Do NOT use images or external icon fonts. Use Unicode characters or inline SVG for icons.
