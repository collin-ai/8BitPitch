<objective>
## Goal
Build the exercise leveling system. XP is the total number of correct answers across all exercises. Level per exercise is derived from the cumulative correct count for that exercise: 25 correct answers = Level 1 for easy exercises (ex01–ex05, which have 5 questions each), 15 correct answers = Level 1 for harder exercises (ex06–ex08, which have 3 questions each). Levels stack linearly. Guests use localStorage; logged-in users use Supabase score data.

## Purpose
The leveling system gives players a sense of progression. It is the data source for the Profile Widget (Phase 12-02) XP and level slides and the High Scores sub-view level badges (Phase 12-03). Building it as a standalone utils module before those plans keeps the dependency clean.

## Output
- New file `utils/levels.js` — `window.BitPitch.Levels` module
- `getTotalXP()` — returns total correct answers across all exercises (number)
- `getLevelForExercise(exerciseId)` — returns current level for a given exercise (integer ≥ 0)
- `getThresholdForExercise(exerciseId)` — returns correct-count per level (25 or 15)
- `recordCorrect(exerciseId, count)` — adds `count` correct answers for an exercise (called from showSummary hook)
- Guest storage: localStorage key `bp_xp_{exId}` (integer, total correct count per exercise)
- Logged-in storage: derived from Supabase scores (sum of correct_count per exercise_id)
- `utils/levels.js` added to script load order in index.html (after supabase.js, before app.js)
</objective>

  <action>
    Create `utils/levels.js` as a new file. Structure:

    ```js
    (function() {
      'use strict';
      if (!window.BitPitch) window.BitPitch = {};

      var EASY_EXERCISES   = ['ex01','ex02','ex03','ex04','ex05'];
      var HARDER_EXERCISES = ['ex06','ex07','ex08'];
      var ALL_EXERCISES    = EASY_EXERCISES.concat(HARDER_EXERCISES);

      var EASY_THRESHOLD   = 25;
      var HARDER_THRESHOLD = 15;

      // In-memory cache: { ex01: 12, ex02: 30, ... }
      // Populated from localStorage (guest) or Supabase (logged-in)
      var _correct = {};
      ALL_EXERCISES.forEach(function(id) { _correct[id] = 0; });

      // ── Guest: localStorage ──────────────────────────────
      function _loadFromLocalStorage() {
        ALL_EXERCISES.forEach(function(id) {
          var val = localStorage.getItem('bp_xp_' + id);
          _correct[id] = val ? parseInt(val, 10) || 0 : 0;
        });
      }

      function _saveToLocalStorage(exerciseId) {
        localStorage.setItem('bp_xp_' + exerciseId, String(_correct[exerciseId]));
      }

      // ── Public API ───────────────────────────────────────
      var Levels = {

        // Call on boot (sync for guest, then call loadForUser async if logged in)
        init: function() {
          _loadFromLocalStorage();
        },

        // Async: load from Supabase scores for logged-in user (overwrites localStorage cache)
        loadForUser: async function() {
          if (!window.BitPitch.Supabase) return;
          var scores = await window.BitPitch.Supabase.getScores();
          if (!scores || !scores.length) return;

          // Reset cache
          ALL_EXERCISES.forEach(function(id) { _correct[id] = 0; });

          scores.forEach(function(s) {
            if (_correct.hasOwnProperty(s.exercise_id)) {
              _correct[s.exercise_id] += s.correct_count;
            }
          });
          // Note: does not write back to localStorage — Supabase is authoritative for logged-in
        },

        getThresholdForExercise: function(exerciseId) {
          return HARDER_EXERCISES.indexOf(exerciseId) !== -1
            ? HARDER_THRESHOLD
            : EASY_THRESHOLD;
        },

        getLevelForExercise: function(exerciseId) {
          var total = _correct[exerciseId] || 0;
          var threshold = Levels.getThresholdForExercise(exerciseId);
          return Math.floor(total / threshold);
        },

        getTotalXP: function() {
          return ALL_EXERCISES.reduce(function(sum, id) {
            return sum + (_correct[id] || 0);
          }, 0);
        },

        // Called from showSummary hook for guest users
        // (Logged-in users: XP derived from Supabase scores on next loadForUser call)
        recordCorrect: function(exerciseId, count) {
          if (!_correct.hasOwnProperty(exerciseId)) return;
          _correct[exerciseId] += count;
          _saveToLocalStorage(exerciseId);
        }

      };

      window.BitPitch.Levels = Levels;
    })();
    ```

    Notes:
    - `init()` is synchronous — safe to call before app.js runs
    - `loadForUser()` is async — call it after session restore in app.js
    - `recordCorrect()` should be called for guest users only; logged-in users get XP from Supabase on next load
    - Do not import or reference any exercise files
