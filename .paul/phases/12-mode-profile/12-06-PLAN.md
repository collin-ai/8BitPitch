<objective>
## Goal
Add a SETTINGS button to the Profile & Settings screen (below the Profile Widget, above the score table) that opens a dedicated Settings screen. The Settings screen provides account management, audio/input preferences, difficulty default, guest data controls, and app info.

## Purpose
Profile & Settings currently combines identity, score history, and navigation into one screen. Settings-specific controls (auth, sound, numpad, difficulty default, data reset) have no home. This plan gives them a dedicated screen that feels consistent with the rest of the app and keeps the Profile screen clean.

## Output
- `#screen-settings` — new screen in index.html
- SETTINGS button in `#screen-profile` below Profile Widget, above score table
- Settings screen header: "PROFILE & SETTINGS" label → back button returns to Profile & Settings
- Settings sections and controls (see tasks for full list)
- CSS for settings screen in style.css
- App.js handlers for each interactive setting
</objective>

## Proposed Settings Sections

### ACCOUNT
| Setting | Logged-In State | Guest State |
|---------|----------------|-------------|
| Account label | Shows username | Shows "PLAYING AS GUEST" |
| Primary button | SIGN OUT → doSignOut() | SIGN IN → showSignIn() |
| Secondary button | — | CREATE ACCOUNT → showRegister() |

### AUDIO & INPUT
| Setting | Control | Storage |
|---------|---------|---------|
| SOUND | Toggle ON/OFF | `bp_sound` ('0' = muted) — same key as per-exercise toggle |
| VIBRATION | Toggle ON/OFF | `bp_vibration` ('0' = off) — new key, checked by Sound module |
| NUMPAD DEFAULT | Toggle ON/OFF | Reads/sets `window.BitPitch.Numpad._on` on boot |

### GAMEPLAY
| Setting | Control | Storage |
|---------|---------|---------|
| DEFAULT DIFFICULTY | 3-button selector: EASY / MEDIUM / HARD | `bp_default_difficulty` — read by startExercise() as initial value |

### DATA
| Setting | Control | Notes |
|---------|---------|-------|
| CLEAR LOCAL DATA | Button → confirm modal | Clears `bp_xp_*` and `bp_local_sessions`; does NOT clear uploaded history or audio prefs |

    ```js
    function renderSettings() {
      // ── ACCOUNT ──
      var nameEl = document.getElementById('settings-account-name');
      var btnsEl = document.getElementById('settings-account-btns');
      if (AppState.currentUser) {
        var username = AppState.currentUser.email.replace('@bitpitch.local','');
        nameEl.textContent = username;
        btnsEl.innerHTML =
          '<button class="btn btn-dim" onclick="AppState.doSignOut()">SIGN OUT</button>';
      } else {
        nameEl.textContent = 'PLAYING AS GUEST';
        btnsEl.innerHTML =
          '<button class="btn btn-primary" onclick="AppState.showSignIn()">SIGN IN</button>' +
          '<button class="btn btn-dim" onclick="AppState.showRegister()">CREATE ACCOUNT</button>';
      }

      // ── SOUND ──
      var soundMuted = localStorage.getItem('bp_sound') === '0';
      var soundBtn = document.getElementById('settings-sound-toggle');
      soundBtn.textContent = soundMuted ? 'OFF' : 'ON';
      soundBtn.classList.toggle('active', !soundMuted);

      // ── VIBRATION ──
      var vibOff = localStorage.getItem('bp_vibration') === '0';
      var vibBtn = document.getElementById('settings-vibration-toggle');
      vibBtn.textContent = vibOff ? 'OFF' : 'ON';
      vibBtn.classList.toggle('active', !vibOff);

      // ── NUMPAD ──
      var numpadOn = window.BitPitch && window.BitPitch.Numpad
        ? window.BitPitch.Numpad._on
        : false;
      var numpadBtn = document.getElementById('settings-numpad-toggle');
      numpadBtn.textContent = numpadOn ? 'ON' : 'OFF';
      numpadBtn.classList.toggle('active', numpadOn);

      // ── DEFAULT DIFFICULTY ──
      var defDiff = localStorage.getItem('bp_default_difficulty') || 'medium';
      ['easy','medium','hard'].forEach(function(d) {
        var btn = document.getElementById('sdiff-' + d);
        if (btn) btn.classList.toggle('active', d === defDiff);
      });
    }
    ```

    **Toggle handlers:**
    ```js
    AppState.toggleSettingSound = function() {
      var muted = localStorage.getItem('bp_sound') === '0';
      localStorage.setItem('bp_sound', muted ? '1' : '0');
      if (window.BitPitch && window.BitPitch.Sound) {
        window.BitPitch.Sound._muted = !muted;
      }
      renderSettings();
    };

    AppState.toggleSettingVibration = function() {
      var off = localStorage.getItem('bp_vibration') === '0';
      localStorage.setItem('bp_vibration', off ? '1' : '0');
      renderSettings();
    };

    AppState.toggleSettingNumpad = function() {
      if (window.BitPitch && window.BitPitch.Numpad) {
        window.BitPitch.Numpad._on = !window.BitPitch.Numpad._on;
      }
      renderSettings();
    };

    AppState.setDefaultDifficulty = function(diff) {
      localStorage.setItem('bp_default_difficulty', diff);
      AppState.difficulty = diff;
      renderSettings();
    };
    ```

    **AppState.clearLocalData():**
    ```js
    AppState.clearLocalData = function() {
      AppState._showRestartModal('CLEAR ALL LOCAL DATA? THIS CANNOT BE UNDONE.', function() {
        ['ex01','ex02','ex03','ex04','ex05','ex06','ex07','ex08'].forEach(function(id) {
          localStorage.removeItem('bp_xp_' + id);
        });
        localStorage.setItem('bp_local_sessions', '[]');
        if (window.BitPitch && window.BitPitch.Levels) {
          window.BitPitch.Levels.init();
        }
        renderSettings();
      });
    };
    ```
