## What Was Done This Session

### Difficulty Explained page — full legibility overhaul (`index.html`, `style.css`)

**Table restructure:**
- Old: 4-column table (VALUE | EASY | MED | HARD)
- New: 2-column table (VALUE | EXAMPLE) with EASY / MED / HARD toggle buttons in the example column header
- Toggle is purely CSS + a small inline `setDiffTab()` JS function — no framework dependency
- Only the active difficulty's example is shown per row; others are `hidden`

**Value column:**
- Simplified to `4k ÷ 3`, `800 ÷ 3`, `25k ÷ 3` — narrow enough to fit at 390px without horizontal scroll
- Exact answer (`= 1,333.33`) removed from value column entirely

**Toggle tabs:**
- No borders — only the active tab lights up in colour (EASY=green, MED=yellow, HARD=red)
- Inactive tabs are dim (`var(--text-dim)`)

**Font sizes increased throughout:**
- Table: 7px → 10px; intro/note: 7px → 10px; section-label: 8px → 11px; title: 9px → 11px

**Grey text → white:**
- `.diff-exp-intro`, `.diff-exp-note`, `.col-tol`, `.ex-label` all use `var(--text)` now

**Intro and note boxes:**
- Both now have `background: #0d1520` and `border: 2px solid var(--border)` — matching table cell aesthetic

**Intro text:**
- "EACH DRILL HAS THREE DIFFICULTY LEVELS. HIGHER DIFFICULTY = TIGHTER TOLERANCE. SELECT EASY, MED, OR HARD BELOW FOR EXAMPLES."

**Hard 2dp note text:**
- "ON HARD, DIVIDE-BY-3 ANSWERS REQUIRE 2 DECIMALS OF PRECISION ENDING IN .33 OR .67. TYPE THE COMPLETE NUMBER (E.G. "3333333.33"). SHORTCUTS LIKE "$3.33M" PARSE TO $3,330,000 AND WON'T MATCH THE 2DP REQUIREMENT."
