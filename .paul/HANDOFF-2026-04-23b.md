## What Was Done This Session

### Numpad styling (`style.css`, `index.html`)
- **Shadow removed** from `.numpad-toggle-btn` (all states: default, active, :active)
- **Shadow removed** from `#numpad-panel`
- **Borders** on `#numpad-panel` and all `.np-btn` changed from `var(--blue)` → `var(--border)` (matches drill card)
- **Number buttons (0–9)**: added `.np-num` class → `color: var(--yellow)`
- **Other button icons** (`,` `.` `K` `M` `◀` `▶` `DEL` `TAB` `ENT`): inherit `var(--border)` from `.np-btn`
- **DEL and 0 swapped** in row 4 (now: DEL → 0 → TAB → ENT)
- **Arrow characters** changed from `&larr;`/`&rarr;` (← →) to `&#9664;`/`&#9654;` (◀▶) — solid triangles, no size change needed
- `.np-arrow` class removed (was a failed attempt to scale arrows; triangles made it unnecessary)

### ex05 Growth Rate Snap (`exercises/ex05-growth-rate.js`)
- **Old structure:** 2 rounds × 3 rates = 6 questions; same base revenue held across each round
- **New structure:** 5 independent questions; each picks fresh `baseRev` from `NICE_REVENUES` and fresh `pct` from `RATE_POOL`
- **Progress display:** `Q X / 5` (was `ROUND X / 2 | RATE X / 3`)
- Removed: `ROUNDS`, `RATES_PER_ROUND`, `round`, `rateIdx`, `roundRates`, `nextRound()`
