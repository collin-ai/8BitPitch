## What Was Done This Session

### Mobile viewport fixes (`style.css`)
- **`min-height: 100dvh`** added below existing `100vh` on `.screen` — fixes layout shift caused by mobile browser chrome appearing/disappearing
- **`font-size: 16px`** added to `.drill-input` inside `@media (max-width: 480px)` — prevents iOS Safari from auto-zooming the viewport on input focus (previously only applied in `.numpad-mode`)
- Viewport meta tag (`width=device-width, initial-scale=1.0`) was already correct — no change needed
